How a match is found

Category match +40%
Required. Different categories never match.
Name match +40% / +20%
Exact name (any case) +40, partial, like "iPhone" and "iPhone 12", +20.
Location match +20%
Same place, like Library, Block A or Hostel.
Total score ≥ 60% is flagged as a match, and both people get a notification.
